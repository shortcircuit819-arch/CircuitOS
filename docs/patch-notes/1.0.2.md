# CircuitOS 1.0.2

September 4, 2026

This update fixes issues found in a deeper review of Twitch connections, saved data, cloud storage, and the editor.

- **More reliable Twitch connections.** Token refreshes stay coordinated across the app, failed redemption subscriptions retry, and reconnects keep receiving events during the handover. Managed rewards are refunded when a pull fails before an inventory write begins.
- **Safer profile operations.** Removing items, resetting viewers, and restoring backups stay attached to the profile selected when the operation began. Profiles with missing or damaged metadata can be opened and renamed again.
- **Portable saves stay discoverable.** ZIP installations keep finding their existing data after the first launch. Automatic updates preserve custom data locations and launch settings.
- **Cloud recovery works more predictably.** Empty cloud profiles fall back to a usable local app with an explanation in Settings. Large tables no longer hide later profiles or inventory, and outdated rolling-backup selections are rejected instead of restoring different content.
- **Unsaved edits stay protected.** Changes made while a save is running remain marked unsaved. Role-name drafts survive automatic refreshes, and refresh/close prompts include overlay and role-name changes.
- **Rate Lab matches the game.** Empty rarity tiers no longer distort the displayed odds.

Update through **Settings → About** or download the new installer.

The release remains unsigned; Windows may display an unknown-publisher prompt. SHA-256 checksums are provided with the release downloads.
