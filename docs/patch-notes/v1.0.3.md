# CircuitOS 1.0.3

## Get ready to stream

- New four-step guide on Overview: connect Twitch, configure a channel-point reward, add the OBS overlay, and verify a real reveal.
- First-run setup now opens that guide after creating your game.
- Clearer Twitch and preview instructions distinguish sample visuals from live redemption checks.

## Demo kit

Three free collection packs are available in [examples/collections](../../examples/collections): fantasy loot, cozy cafe, and space discoveries. Each imports as a separate profile and adopts your current theme. Demo screenshots and a preview recording are in [the demo kit](../demo-kit.md).

No saved-data schema changes. Existing catalogs and inventories retain their format. Windows x64 installers remain unsigned; verify downloads against the release checksums.
