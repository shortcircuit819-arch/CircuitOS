# CircuitOS 1.0 — Stable release

The first stable public release. Everything built across 0.4–0.9 comes together here: the configurable
collection game, native zero-config Twitch, multiple profiles and modules, item variants and rarity
tiers, the CircuitOS design language, and a real Windows installer with in-app auto-updates.

## What 1.0 means

- **Stable, and staying that way.** Your saved data — collections, inventories, profiles, backups,
  settings — carries forward from here. Updates keep your data folder untouched.
- **Auto-updates are live.** Install with `CircuitOS-win-Setup.exe` once, and future versions arrive
  through **Settings → About → Check for updates**. No re-downloading, no reconfiguring.

## About the "unknown publisher" warning

CircuitOS 1.0 ships **unsigned**, so Windows SmartScreen shows an "unknown publisher" warning the first
time you run the installer. This is expected — click **More info → Run anyway**. Every release also
publishes a SHA-256 checksum so you can verify your download against the build. Never disable antivirus
to run it. See `docs/installation-and-updates.md`.

## Notes

- This is CircuitOS's first published release, so everyone starts with a fresh install. From 1.0 onward,
  new versions arrive automatically through the in-app updater.
- Local storage stays the default; the optional bring-your-own Appwrite backend is unchanged.
