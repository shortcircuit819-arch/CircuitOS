# CircuitOS 1.1.0

## Achievements for new and existing viewers

Viewers can earn permanent badges for their first item, 25%, 50%, and completion of each collection. Small collections can award several milestones on one pull. Add custom goals for collection percentage, unique items owned, completed collections, or pulls since tracking began.

The new Achievements screen configures goals, optional Scrap rewards, chat announcements, and OBS celebrations. Viewer Inventory shows earned badges and progress. The configurable `!badges` command lists a viewer's awards with numbered pages. Older profiles receive unused command aliases without changing their existing commands.

## Existing collections count immediately

On startup, CircuitOS checks all profiles, including inactive games, using existing holdings and saved completion records. Saving achievement settings also checks existing viewers in that profile. No extra redemption is needed.

Historical awards are silent and credit any configured reward once. They are marked as backfilled without inventing an earning date. Automatic rewards default to zero. Lifetime pull tracking starts from this upgrade; past pulls cannot be reconstructed from current inventory.

## Safe, lasting records

An earned award keeps its recorded name and reward after goal edits or removal. Award records and currency are committed together with inventory backups; repeated checks do not pay again. Invalid settings and malformed imports are rejected. Failed checks preserve inventory and appear in Achievements for retry, while other healthy profiles can continue.

Read the [achievements guide](../achievements.md) for setup, reward behavior, and recovery details. This feature ships as 1.1.0; deeper streamer analytics follows separately. Windows x64 installers remain unsigned.
