# CircuitOS 1.0.1 — Safer collections

A quality release. Nothing new to set up — this is a tune-up of 1.0 after a full top-to-bottom
review. Most of the work went into protecting viewer collections, so an unlucky moment can't cost
anyone their items.

## Your viewers' collections are safer

- **Editing while a pull lands can no longer drop items.** If you were editing a viewer in the admin
  panel at the exact moment they redeemed a pull, one of those two changes could quietly get lost.
  Collection saves now take turns, so both always stick.
- **A bad read can't wipe a collection.** If the collection file is ever unreadable for a moment — a
  cloud-sync hiccup, say — CircuitOS now cancels that pull and refunds the channel points instead of
  saving an empty collection over what was there. Nobody loses their items to a hiccup.
- **Collections now have restorable backups.** Every time collections are saved, CircuitOS keeps a
  timestamped copy you can roll back to from the **Backup & Recovery Center**. Before, it kept only a
  single hidden copy; now you have real history to restore from if you ever need it.

## Fewer ways for a single mistake to spread

- **One broken event collection no longer breaks every pull.** If an event collection is misconfigured,
  it now just sits itself out — everyone else's redemptions keep working normally, instead of the bad
  one taking pulls down for the whole channel.
- **Event timing is consistent.** The window an event is "live" for now matches exactly between the
  pulls themselves and what your collection chat command reports, so they never disagree.

## Login security

- **Faster token protection on upgrade.** If you're coming from a much older version, your saved Twitch
  login is now re-secured the moment CircuitOS starts, rather than sometime later in the session.
- Plus some minor hardening on the local connection behind the admin panel.

## Admin panel polish

Small annoyances from day-to-day use, cleaned up:

- **Fits a smaller window.** The panel works docked beside OBS without forcing you to scroll sideways.
- **The catalog editor stays put.** It no longer jumps back to the top every time you change an item.
- **Everything's there on load.** All navigation groups show up right away.
- **Bulk cleanup.** Select several items at once and remove them in one go.
- **The Pull Rates / Rate Lab slider fills all the way** to the end of its track.
- **Light theme looks right.** Date and number pickers are no longer stuck in dark colors on the light
  theme.
- **Clearer Save.** The Save button in the top bar now spells out what it's saving.
- Clearer wording on a few setup and Twitch screens.

## Notes

- Your data carries over untouched. This is an in-place update from 1.0 — install it over the top and
  everything (collections, profiles, backups, settings) stays exactly as it was.
- Nothing about how you set up or run your game changes; it's the same CircuitOS, steadier underneath.
