# CircuitOS 1.0.4

## Slider handle alignment

Fixed the white handle stopping short of the ends of the colored pull-weight track. Range inputs inherited horizontal padding intended for text fields, which inset the handle without insetting the fill. The slider now has zero padding and retains its previous rendered height.

Overview and Rate Lab sliders remain editable. Weight values, pull calculations, inventory data, and saved-data schemas are unchanged. Windows x64 installers remain unsigned.

## Compact setup guide

The Overview setup guide starts collapsed for existing installations and remembers whether you expand or collapse it. New users see it expanded after completing the wizard. Reopen it from its heading whenever needed.
